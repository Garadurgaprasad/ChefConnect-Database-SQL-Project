           Stored procedures (Q85 - Q91), triggers (Q92 - Q97) and the stored

           implemented as equivalent SQLite triggers and helper code and every
           test written in Hard_queries.txt was run against them. Each test

           Hard_queries.txt.
           In your own MySQL run you will also see: "(0.00 sec)" timings, a
           "Rows matched / Changed" line after UPDATE, a different changed_at
           time, and AUTO_INCREMENT numbers that keep counting after a

           be higher on a second run.
